# Las Aventuras de Zacarías

Motor base v0.1.0 para cuento infantil interactivo.

## Qué incluye

- Portada con Zacarías interactivo.
- Ronroneo sintético al tocar a Zacarías.
- Botón "Comenzar la aventura".
- Lector con texto a la izquierda e imagen a la derecha.
- Texto corto por escena.
- Diseño responsive para celular, tablet y computador.

## Próximo paso

Subir ilustraciones por escena en:

`assets/illustrations/`

Nombres sugeridos:

- `escena-001.png`
- `escena-002.png`
- `escena-003.png`
- `escena-004.png`

Luego se agregan en `app.js` dentro de la propiedad `image`.
